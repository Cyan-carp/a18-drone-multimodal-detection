## 环境事实（2026-11-18 实测）

- 系统 `java` 垫片崩溃（`0xC0000409`）→ 使用便携 JDK 17（`.tools/jdk17`）。
- **Maven 未安装**，`.m2` 为空 → 脚本下载 3.9.9 到 `.tools/maven`，配阿里云镜像。
- **系统 Node 22 加载 `node_modules` 即崩**（`0xC0000005`）→ 使用便携 Node 20（`.tools/node20`），并清空注入的 `NODE_OPTIONS`。
- 前端安装必须 `npm install --ignore-scripts`（esbuild postinstall 崩溃；平台二进制由 `@esbuild/win32-x64` 提供）。
- Python 3.13 仅用于文档检查器；后端不依赖 Python。
- 交付包路径含 `[A18]` 方括号，PowerShell 必须用 `-LiteralPath`。
