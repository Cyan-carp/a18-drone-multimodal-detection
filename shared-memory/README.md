# 协作记忆规则

本目录保存跨会话的协作上下文，**不替代** `docs/` 中的正式记录。

## 分层

| 文件 | 放什么 | 不放什么 |
| --- | --- | --- |
| `project-memory.md` | 已确认、跨对话稳定的前提：范围决策、环境事实、关键取舍、排除项 | 阶段进度、临时结论、待讨论问题 |
| `YYYYMMDD-<主题>.md` | 单次会话的过程：试过什么、验证到什么程度、下一步动作 | 密钥、隐私数据、未脱敏日志、大段代码 |

## 新建会话文件

命名 `20261118-目录治理.md` 形式，首行写明目标与基线提交/时间。会话结束前整理出三件事：确认的结论、验证结果、下一步第一动作。

## 边界

- 与正式文档冲突时以正式文档为准，并回头修正记忆文件。
- 稳定事实沉淀到 `project-memory.md` 前，必须已经在正式文档或实际验证中成立。
- 不记录访问凭证、内网地址、个人信息；不粘贴完整日志文件，只写摘要与路径。
