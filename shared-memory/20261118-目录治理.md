## 踩坑记录（供后续会话复用）

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `Test-Path` 对交付包路径返回 False | 路径含 `[A18]`，方括号被当作通配符字符类 | 一律加 `-LiteralPath` |
| 命令无返回、工具报 `No result found` | `Add-Content` 未指定编码，被安全策略拦截 | 显式 `-Encoding utf8`，或改用文件编辑工具 |
| `Remove-Item -LiteralPath` 报参数无法绑定 | 执行环境把 cmdlet 包装成代理函数，不支持该参数 | 改用 `[IO.Directory]::Delete($path,$true)` |
| `java -version` 无输出 | 执行环境对 stderr 捕获有限 | 以文件版本或实际构建结果为准，不依赖该输出 |
