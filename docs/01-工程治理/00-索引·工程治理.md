# 索引 · 工程治理

本分区定义"信息写到哪、怎么命名、改完同步什么"。它面向维护者，不描述产品行为。

| 页面 | 回答的问题 | 状态 |
| --- | --- | --- |
| [文档与目录治理规范](01-文档与目录治理规范.md) | 事实源、目录归属、命名与元数据、链接规则、页长阈值、谁能改规则 | 现行 |
| [变更同步矩阵](02-变更同步矩阵.md) | 某类改动发生后，哪些文件必须同批更新，哪些不该动 | 现行 |

## 使用方式

1. 动手前：用规范第 2 节判断你的改动属于哪类信息，找到唯一正文。
2. 动手后：用矩阵第 1 节确认最小同步集，再运行检查器。
3. 规则需要变更时：先给出条款、理由、影响范围，经负责人确认后改正文，不同时保留两种写法。

## 边界

- 本分区不写具体阶段进度（去 [当前系统状态](../00-当前系统状态.md)）。
- 本分区不写接口细节（去 [接口契约](../02-方案与契约/02-前后端接口契约.md)）。
- 本分区不重复根 [AGENTS.md](../../AGENTS.md) 的工作区边界条款，只做引用。
