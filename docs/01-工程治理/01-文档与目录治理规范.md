# 文档与目录治理规范

## 1. 适用范围与原则

- 适用：本仓库（`05_演示平台开发仓库`）内全部正式文档与目录结构。
- 不适用：仓库外交付包 `01_`～`04_`，它们是只读证据，不按本规范重排。
- 三条原则：
  1. **一类信息只有一个正文**，其他位置只链接或摘要。
  2. **目录先按用途分**，再按模块分；不为格式对称创建空分区。
  3. **可验证**：机械项交给脚本，语义项由人核对，两者都不通过不算完成。

## 2. 事实源归属

| 信息类型 | 唯一正文 | 其他页面怎么做 |
| --- | --- | --- |
| 现在处于什么阶段、有什么能力与限制 | [当前系统状态](../00-当前系统状态.md) | 只给链接，不堆日期快照 |
| 长期规则（文档、目录、同步、边界） | 本页与[变更同步矩阵](02-变更同步矩阵.md) | 引用条款，不复制相反表述 |
| 设计、算法、接口契约 | [方案与契约](../02-方案与契约/00-索引·方案与契约.md) | 计划页引用，不复述字段清单 |
| 阶段计划与验收判定 | [开发计划与验收](../03-开发计划与验收/00-索引·开发计划与验收.md) | 状态页引用验收结果 |
| 历史盘点、迁移与原始证据 | [历史与证据](../09-历史与证据/00-索引·历史与证据.md) | 状态页给摘要与链接 |
| 可执行命令 | `scripts/*.ps1`、各目录 README | 文档只写入口与副作用 |
| 协作过程与跨会话上下文 | [shared-memory](../../shared-memory/README.md) | 不替代正式记录 |

冲突处理顺序：原始文件（含哈希）→ 实测回执 → 状态页 → 其余文档。**不得为了让文档自洽而修改历史记录。**

## 3. 目录归属与元数据

| 用途 | 路径 | 入口 | 元数据 | 入库 |
| --- | --- | --- | --- | --- |
| 正式文档 | `docs/` | [导航](../00-导航·项目文档.md) | `status` `scope` `updated` | 是 |
| 协作记忆 | `shared-memory/` | `README.md` | 文件名含日期与主题 | 是（不含敏感信息） |
| 工具与配置 | `tools/` | `check_docs.py` 帮助 | 无 | 是 |
| 参数参考 | `config/reference/` | `README.md` | 来源与用途说明 | 是 |
| 归档资产 | `legacy/` | `README.md` | 说明弃用原因 | 是 |
| 运行时产物 | `data/` | — | 不入库 | 否 |
| 源码 | `src/`、`frontend/` | 各自 README | 无 | 是 |

元数据规则：

- `status` 取值仅 `草稿`、`现行`、`历史`、`废弃`。
- `scope` 写这篇文档覆盖的范围（板块或子系统），不写"全部"以外的模糊表述。
- `updated` 用 `YYYY-MM-DD`，表示正文最后实质变更日，不因改错别字而改。
- 四态含义：`草稿` 未定稿不作为依据；`现行` 是当前依据；`历史` 保留事实但不再指导决策；`废弃` 明确不可引用。

## 4. 命名与链接

- 目录 `NN-名称`，`NN` 表示阅读顺序，不表示优先级。
- 目录内文档达到 2 篇及以上时，必须有 `00-` 前缀索引；索引文件名带分区名（如 `00-索引·工程治理.md`），因为全库文件名必须唯一。
- 文档文件名用"编号 + 主题"，不加日期；日期进正文或 frontmatter。
- 链接优先相对路径 Markdown 链接；仅当全库同名唯一时才用 `[[双名]]`。
- 指向仓库外的交付材料时写相对路径（如 `../../04_演示系统代码包/...`），不写本机绝对路径。
- 单篇正文上限 15000 字符；超过时按主题拆分，并在索引中登记，不删事实。

## 5. 谁能改规则

- 规则正文的修改权属于项目负责人（用户）。AI 会话可提出条款、理由与影响范围，但需明确同意后才能改写本页。
- 一次性排障结论不自动升级为规则；若确需长期约束，按上一条走审批。
- 阶段进度、验收结论由实施者填写，但必须附可复核证据（命令、路径、回执摘要）。

## 6. 校验

```powershell
python tools/check_docs.py --root . --config tools/governance-config.json
```

机械项：frontmatter 必填字段与取值、日期格式、目录索引、文件名重名、Markdown 链接与 wikilink 可达、单页字符上限。

语义项（人工，不能由脚本代劳）：

1. 状态页的"已完成"是否能指向实际代码与运行结果。
2. 计划页里的"待办"是否被误写成状态。
3. 历史证据是否被后见之明改写。
4. 是否存在同一事实的两份正文。
5. 是否把密钥、私有数据或未脱敏日志写进仓库。
