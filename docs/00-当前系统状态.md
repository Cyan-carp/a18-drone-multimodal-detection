## 4. 已知限制

1. **未在干净机器验证**：当前所有验证都在已具备 `.tools`（JDK17 / Maven / Node20）的本机完成，首次联网引导流程未在空缓存环境重跑。
2. **不能离线构建**：`.tools` 与 `%USERPROFILE%\.m2` 为空时需要联网。
3. **上传图像无真值**：`metrics` 返回 `null`，前端隐藏 P/R 对比条，这是设计行为而非缺陷。
4. **数值非实测**：界面展示的类别 AP 与 mAP 来自 `config/reference/wbf_best_current.json`（原模型在 VEDAI 上的历史结果），演示中一律标注"模拟模式"。
5. **无版本控制**：文件移动与改名没有历史，依赖哈希清单追溯。
