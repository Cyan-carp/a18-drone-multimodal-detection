# 后端实施计划

## 风险与回退

| 风险 | 表现 | 应对 |
| --- | --- | --- |
| Maven 与依赖下载失败 | 首次构建中断 | 脚本重试 + 明确报错与手动安装指引；不静默跳过 |
| 中文字符乱码 | 控制台/CSV 乱码 | 后端 `-Dfile.encoding=UTF-8`；CSV 加 BOM |
| Java2D 无字体 | 生成图上中文丢失 | 图像不渲染任何文字，图例交给前端 |
| SSE 被代理缓冲 | 进度不动 | 设 `X-Accel-Buffering: no`，并保留轮询兜底 |

回退：本仓库副本可随时按 [基线复制清单](../09-历史与证据/02-基线复制清单.md) 从 `04_` 重新复制；不在原包上回滚。
