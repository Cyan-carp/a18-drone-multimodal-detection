# 前端实施计划

目标形态：React 18 + TypeScript + Vite 5 + Tailwind 3.4.17 的深色指挥中心控制台，三个路由页面，检测过程可见、结果可对照、任务可回溯。

## F0 工程与设计令牌

| 项 | 内容 |
| --- | --- |
| 交付物 | `frontend/` 可 `dev` 与 `build` 的工程；`index.css` 中的设计令牌；`vite.config.ts` 的 `/api` 代理 |
| 关键动作 | 固定 Vite 5、Tailwind 3.4.17、`tailwind-merge ^2.5.5`、`tailwindcss-animate`、`lucide-react`；`verbatimModuleSyntax=false`、关闭 `noUnusedLocals/Parameters`；`server.host=0.0.0.0`、`allowedHosts=true` |
| 完成判定 | `npm run build` 零错误；空壳页面可访问；暗色底与字色符合令牌 |

## F1 布局壳与数据层

| 项 | 内容 |

| 交付物 | `AppShell`（左 64px 图标导航 + 顶 56px 状态条）、路由懒加载、`lib/api.ts`、`lib/types.ts`、`hooks/useSSE.ts` |

| 项 | 内容 |
| --- | --- |
| 交付物 | `ScenePicker`、`UploadPanel`、`DualCanvas`、`BranchToolbar`、`ParamPanel`、`RunProgress`、`StatCards`、`DetectionTable`、`ClassBars`、`MetricCompare` |

## 与计划的差异登记

- 早期方案写的是 Vite 6，构建规范固定 Vite 5，以规范为准；升级需单独评估。
- 不引入图表库：类别分布用 CSS 条形，避免为单个组件增加打包体积。
- 不做表格虚拟化：单页不超过 50 行。
