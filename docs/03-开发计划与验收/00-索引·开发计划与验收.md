## 使用规则

- 计划页说明"怎么做、做完什么样"，不记录完成度；完成度只写 [当前系统状态](../00-当前系统状态.md) 与 [验收清单](03-验收清单.md)。
- 阶段顺序按编号推进；跨阶段取巧（先写 UI 再补接口）必须先在计划页登记，否则验收时无法定位问题。
- 完成一个阶段：更新验收清单状态列 → 更新状态页能力行 → 在 `shared-memory` 记一条验证结论，三处一致才算完成。
- 计划与实现冲突时，先判断是计划过时还是实现偏差；过时就改计划，不要留两份说法。
