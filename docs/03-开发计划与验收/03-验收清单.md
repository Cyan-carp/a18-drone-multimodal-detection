## 校验器有效性（2026-11-18）

只报 PASS 不能证明检查器有效，因此做了一次负向测试：

1. 复制 `docs/` 到临时目录，在 `00-当前系统状态.md` 末尾追加 `[broken](nope-does-not-exist.md)`；
2. 以临时目录为 root 运行检查器 → `FAIL: 11 issue(s)`，其中包含 `broken Markdown link: ... (nope-does-not-exist.md)`；
3. 其余 10 条是临时目录缺少仓库根 `README.md`、`AGENTS.md`、`legacy/` 等目标所致，同时也验证了跨目录链接确实按 root 解析；
4. 临时目录已删除，真实仓库复检仍为 `PASS: docs document checks`。

结论：检查器能识别真实断链，A1 的 PASS 不是"空跑通过"。
