# 界面设计规范

界面语言采用 **PersonalGate UI 通用技能**（`personalgate-ui-universal`）的设计基线：白色主区、浅灰窄侧栏、少量蓝色强调、1px 细边框、圆角卡片、克制阴影，深浅双主题。此前的深色 HUD / 青色霓虹方向已废弃。

## 1. 色彩角色

变量以 `R G B` 三元组存放在 `frontend/src/index.css`，Tailwind 通过语义类名读取，组件不写死色值。

| 用途 | 浅色 | 深色 | Tailwind 类 |
| --- | --- | --- | --- |
| 页面背景 | `#ffffff` | `#15181e` | `bg-ink-950` |
| 侧栏 | `#f4f6f9` | `#1b1f27` | `bg-ink-900` |
| 卡片表面 | `#ffffff` | `#20252f` | `bg-ink-850` |
| 状态条 / 表头 | `#f8faff` | `#222c3c` | `bg-ink-800` |
| 卡片边框 | `#e4e8ef` | `#343d4e` | `border-ink-700` |
| 控件边框 | `#e0e5ef` | `#3a4457` | `border-ink-600` |
| 主文字 | `#1c2538` | `#e6ebf4` | `text-text-primary` |
| 页面标题 | `#111827` | `#f1f4fa` | `text-text-strong` |
| 辅助文字 | `#68738a` | `#a2afc5` | `text-text-secondary` |
| 主按钮 / 强调 | `#4864ff`（白字） | 同左 | `bg-signal-cyan` |
| 成功 / 警告 / 危险 | `#16a34a` / `#d97706` / `#dc2626` | `#34d399` / `#fbbf24` / `#f87171` | `signal-green/amber/red` |

数据可视化色（检测框、图例）：car `#4864ff`、truck `#12a150`、bus `#d97706`、van `#7c5cff`、freight_car `#dc2626`。这些只标识类别，不表达状态。

类名沿用改造前的 `ink / signal / text` 前缀，但取值改由上述角色提供，因此同一套组件自动适配两种主题，无需逐文件改写。

## 2. 字阶与排版

| 角色 | 字号 / 字重 | 实现 |
| --- | --- | --- |
| 页面标题 | 32 / 700（<1280px 降为 30） | `.page-title` |
| 指标数字 | 28 / 600 | `.metric-value` |
| 小节标题 | 15 / 500 | `.section-title` |
| 正文 | 14 / 400 | body |
| 控件、表格 | 13 / 400 | 按钮与表格单元 |
| 辅助、表头 | 12 / 400 | `text-[12px]` |
| 侧栏短标签 | 11 / 400 | SideNav |

字体栈 `Microsoft YaHei UI → Microsoft YaHei → Segoe UI → system-ui`，数字用 `tabular-nums`；**不联网加载字体**，避免内网环境掉字。

## 3. 几何

| 项 | 值 |
| --- | --- |
| 侧栏宽 | 92px；导航按钮 62×62，圆角 13 |
| 主区内边距 | 左右 34（<1024 为 24），上 16 |
| 卡片圆角 / 内边距 | 16px / 20×22 |
| 控件圆角 / 高度 | 9px / 36px |
| 状态条、场景卡 | 12px 圆角 |
| 徽标圆角 | 6px |
| 表格行高 | 约 46px（上下 13px 内边距） |
| 卡片间距 | 16px |
| 滚动条宽 | 7px |

阴影仅用于区分相邻表面：浅色 `0 2px 18px rgba(33,57,104,.047)`，深色 `0 2px 18px rgba(0,0,0,.118)`。不使用发光、玻璃模糊、大渐变、HUD 网格与装饰性扫描线。

## 4. 组件与状态

- **主按钮**：蓝底白字，hover `#3a55ed`、active `#3049d6`；每屏只留一个主操作（开始检测、提交批次）。
- **次按钮**：描边 + 表面色；**链接按钮**：无边框；破坏性操作走 `danger` 并要求确认。
- **输入/下拉**：36px 高、1px 边框、聚焦时蓝色边框；标签与控件关联，长值 tooltip 显示全文。
- **表格**：浅表头、弱水平线、无竖网格；整行 hover；选中行用 `--pg-selected` 底色，不只用颜色区分（选中列仍有勾选图标）。
- **徽标**：同时有文字与圆点，不单靠颜色表达状态。
- **空态**：给出下一步动作（如"选择场景后点击开始检测"），未运行与"无真值"分别给不同文案。
- **忙碌/失败**：检测中禁用参数面板并显示阶段进度；失败通过 toast + 任务状态 `失败` 双通道反馈。

## 5. 主题

- 默认浅色；首次访问读取 `prefers-color-scheme`，之后以 `localStorage['a18-theme']` 为准。
- 首屏前由 `index.html` 内联脚本写入 `data-theme`，避免闪白/闪黑。
- 顶栏 36×36 按钮切换，图标为 Sun/Moon，具备 `aria-label` 与可见焦点。
- 主题只影响外观，不重置表单、不触发重新检测、不覆盖正在编辑的参数。

## 6. 响应式与可达性

- 三栏（≥1280px）→ 单栏堆叠（<1280px），窄屏时画布优先展示，参数与场景依次下移。
- 任务表最小宽度 760px，容器横向滚动，不让整页被撑出横向滚动条。
- 键盘可达：所有交互元素为原生 `button` / `input` / `select`，分段控件使用 `role="tab"` + `aria-selected`，全局 `:focus-visible` 2px 描边。
- 文案不使用占位描述；数据未知显示 `—` 而不是 `0`。

## 7. 与旧版的差异

| 维度 | 旧版 | 现版 |
| --- | --- | --- |
| 主题 | 仅深色 | 浅色默认 + 深色 |
| 强调色 | 青 `#22D3EE` | 蓝 `#4864ff` |
| 卡片 | 12px 圆角、微光 | 16px 圆角、轻阴影 |
| 侧栏 | 64px 图标 | 92px 图标 + 短标签 |
| 背景 | HUD 网格 + 扫描线 | 纯色 + 细边框 |
| 字阶 | 13/11 为主 | 32/28/15/14/13/12 |

## 8. 未采用项

- 未引入 Radix 等 UI 运行库：现有组件够用，避免为配色改造增加依赖。
- 未复刻源应用的六个导航项与品牌元素，仅迁移视觉与交互方法。
