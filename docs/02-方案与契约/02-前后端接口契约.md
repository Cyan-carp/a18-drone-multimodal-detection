# 前后端接口契约

本页是前后端唯一对接依据。字段、状态码、事件名以此为准；实现与本文冲突时先改实现，或同批修订本文（见 [变更同步矩阵](../01-工程治理/02-变更同步矩阵.md)）。

## 1. 通用约定

| 项 | 约定 |
| --- | --- |
| 前缀 | 全部接口以 `/api` 开头 |
| 编码 | UTF-8；响应 `application/json`，图片为 `image/png` |
| 时间 | ISO-8601 本地时间字符串，如 `2026-11-18T14:03:21` |
| 坐标 | `box = [x1, y1, x2, y2]`，图像原始像素坐标，左上角为原点，`x2 > x1`、`y2 > y1` |
| 分页 | `page` 从 1 开始，`size` 默认 10，上限 50 |
| 鉴权 | 无（仅本地演示） |
| 跨域 | 允许 `http://localhost:5173` 与 `127.0.0.1:5173` |

错误响应统一结构：

```json
{ "code": "RUN_NOT_FOUND", "message": "检测任务不存在", "detail": "R-20261118-0007", "timestamp": "2026-11-18T14:03:21" }
```

| HTTP | code 示例 | 触发场景 |
| --- | --- | --- |
| 400 | `PARAM_INVALID` | 参数越界（conf ∉ [0,1]、imgsz 非 640/1024、两个模态都未提供） |
| 404 | `RUN_NOT_FOUND` / `SCENARIO_NOT_FOUND` | 资源不存在 |
| 409 | `RUN_NOT_DELETABLE` | 删除运行中的任务 |
| 500 | `INTERNAL_ERROR` | 未预期异常（不返回堆栈） |

## 2. 端点一览

### 2.1 场景

| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| GET | `/api/scenarios` | — | `ScenarioSummary[]` |
| GET | `/api/scenarios/{id}` | — | `Scenario` |
| GET | `/api/scenarios/{id}/image` | `modality=rgb\|ir` | PNG 字节流 |
| POST | `/api/system/regenerate-scenarios` | — | `{ "generated": 10, "elapsedMs": 2314 }` |

### 2.2 上传

| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| POST | `/api/uploads` | `multipart/form-data`，字段 `rgb`、`ir` 至少其一 | `UploadInfo` |
| GET | `/api/uploads/{id}/image` | `modality=rgb\|ir` | PNG/JPEG 字节流 |

限制：单文件 ≤ 20MB；仅 `image/png`、`image/jpeg`；只有单模态时另一侧字段为 `null`。

### 2.3 检测任务

| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| POST | `/api/runs` | `CreateRunRequest` | `RunRecord`（`status=QUEUED`，立即返回） |
| GET | `/api/runs/{id}` | — | `RunRecord` |
| GET | `/api/runs/{id}/stream` | — | SSE 流（见 §4） |
| GET | `/api/runs` | `page`、`size`、`status`、`keyword`、`sourceType` | `PageResult<RunSummary>` |
| DELETE | `/api/runs/{id}` | — | `204`；运行中返回 409 |
| POST | `/api/runs/batch-delete` | `{ "ids": ["R-..."] }` | `{ "deleted": 3, "skipped": 1 }` |
| GET | `/api/runs/{id}/export` | `format=json\|csv` | 文件下载 |
| GET | `/api/runs/export` | `format=csv`，可带列表筛选参数 | 文件下载 |

### 2.4 批量任务

| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| POST | `/api/batches` | `{ "scenarioIds": ["SC-001"], "params": DetectParams }` | `BatchJob` |
| GET | `/api/batches` | `page`、`size` | `PageResult<BatchJob>` |
| GET | `/api/batches/{id}` | — | `BatchJob`（含子任务进度） |
| DELETE | `/api/batches/{id}` | — | `204`；运行中返回 409 |

### 2.5 日志与系统

| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| GET | `/api/logs` | `limit`（默认 200，上限 500）、`level`、`keyword` | `LogEntry[]` |
| GET | `/api/logs/stream` | — | SSE 流，事件名 `log` |
| GET | `/api/system/info` | — | `SystemInfo` |

## 3. 数据结构

```jsonc
// ScenarioSummary
{ "id": "SC-003", "name": "城郊路口·夜间", "weather": "夜间", "terrain": "城郊",
  "density": "中", "objectCount": 14, "width": 1024, "height": 1024,
  "rgbUrl": "/api/scenarios/SC-003/image?modality=rgb",
  "irUrl": "/api/scenarios/SC-003/image?modality=ir" }

// Scenario = ScenarioSummary + 真值（上传来源无此字段）
{ "objects": [ { "id": 1, "cls": "car", "box": [120, 340, 168, 384] } ] }

// UploadInfo
{ "uploadId": "U-20261118-0001",
  "rgbUrl": "/api/uploads/U-20261118-0001/image?modality=rgb", "irUrl": null,
  "width": 1024, "height": 1024 }

// DetectParams（缺省值即模拟引擎默认值）
{ "conf": 0.10, "iou": 0.58, "imgsz": 1024,
  "branches": { "rgb": true, "ir": true, "dual": true } }

// CreateRunRequest
{ "sourceType": "scenario", "sourceId": "SC-003", "params": { "conf": 0.10, "iou": 0.58, "imgsz": 1024 } }

// RunRecord
{ "runId": "R-20261118-0007", "status": "SUCCESS",
  "createdAt": "2026-11-18T14:03:21", "finishedAt": "2026-11-18T14:03:22",
  "source": { "type": "scenario", "id": "SC-003", "name": "城郊路口·夜间" },
  "image": { "width": 1024, "height": 1024,
             "rgbUrl": "/api/scenarios/SC-003/image?modality=rgb",
             "irUrl": "/api/scenarios/SC-003/image?modality=ir" },
  "params": { "conf": 0.10, "iou": 0.58, "imgsz": 1024,
              "branches": { "rgb": true, "ir": true, "dual": true } },
  "branches": {
    "rgb": { "weight": 1.70, "elapsedMs": 214,
             "detections": [ { "cls": "car", "conf": 0.93, "box": [120, 340, 168, 384] } ] },
    "ir":  { "weight": 1.95, "elapsedMs": 188, "detections": [] },
    "dual": { "weight": 3.15, "elapsedMs": 402,
              "models": [ { "name": "dual_l", "weight": 1.20, "elapsedMs": 140, "detections": [] } ] }
  },
  "fused": [ { "cls": "car", "conf": 0.91, "box": [121, 339, 169, 385], "sources": ["rgb", "ir", "dual_l"] } ],
  "metrics": { "tp": 11, "fp": 2, "fn": 1, "precision": 0.846, "recall": 0.917 },
  "elapsedMs": 1180 }

// RunSummary：runId、status、createdAt、source、fusedCount、elapsedMs、metrics.recall|null
// BatchJob：batchId、status(RUNNING|SUCCESS|PARTIAL|FAILED)、createdAt、total、completed、failed、runIds[]
// PageResult：items[]、page、size、total、totalPages
// LogEntry：seq、ts、level(DEBUG|INFO|WARN|ERROR)、scope、message、runId|null
// SystemInfo：mode("MOCK")、version、jdk、port、scenarioCount、runCount、branchWeights、models[]
```

状态取值：`RunStatus = QUEUED | RUNNING | SUCCESS | FAILED`；成功才写 `fused` 与 `metrics`。

## 4. SSE 事件

`GET /api/runs/{id}/stream`，`Content-Type: text/event-stream`，统一 `event:` + `data:`（单行 JSON）：

| event | data | 说明 |
| --- | --- | --- |
| `progress` | `{stage, percent, message, ts}` | 阶段推进；`stage` 取 `LOAD/RGB/IR/DUAL/FUSE/POST/DONE` |
| `log` | `LogEntry` | 与全局日志同构，前端可原地插入日志面板 |
| `result` | `RunRecord` | 终态结果，随后服务端关闭流 |
| `error` | `{message, code}` | 失败终态，随后关闭流 |

规则：连接建立后立即补发一条当前状态的 `progress`，避免前端等待空白；心跳每 15s 一次注释行 `: ping`；断流后前端降级为 `GET /api/runs/{id}` 500ms 轮询。

## 5. 导出格式

CSV：

- 首行 BOM `\uFEFF`（保证 Excel 正确识别中文），行尾 `\r\n`。
- 表头：`任务ID,场景,来源类型,类别,置信度,来源分支,x1,y1,x2,y2`
- 置信度保留 4 位小数；`来源分支` 用 `|` 连接，如 `rgb|ir|dual_l`。
- 文件名：`run_{runId}.csv` / `runs_{yyyyMMddHHmmss}.csv`。

JSON：直接输出 `RunRecord`（单条）或 `RunRecord[]`（列表），字段名不做驼峰转换以外的处理。

## 6. 兼容与变更

- 新增字段属兼容变更，前端需容错（缺字段不崩）。
- 删除或重命名字段、改事件名、改状态取值属破坏变更：必须同批改契约、后端、前端，并在 [验收清单](../03-开发计划与验收/03-验收清单.md) 留下记录。
- 模拟引擎替换为真实推理服务时，本契约不变；若真实服务无法满足字段，先在本文登记差异，再决定适配还是改契约。
